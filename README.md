# Saloni Hindlekar | Personal Portfolio Website

Welcome to my personal portfolio website!

This website showcases my academic journey, skills, certifications, projects and experiences as a BBA student pursuing Digital Business and Entrepreneurship at IIM Bangalore.

## About the Project

This portfolio is designed to present my academic work, creative ideas and interest in business, entrepreneurship, sustainability and problem-solving through a clean and professional digital experience.

The website features a warm brown, cream and ivory colour palette with a modern, elegant design.

## Website Sections

- **Home:** Personal introduction and profile photograph.
- **About Me:** Academic background and interests.
- **Education:** Academic journey and qualifications.
- **Skills & Certifications:** Professional skills and certifications.
- **Projects & Academic Experience:** Six academic projects showcasing innovation, research, teamwork and business thinking.
- **Featured Work:** BREWTILE and REFORMED projects showcased through Somaiya University's institutional gallery.
- **Contact:** Email and LinkedIn information.

## Featured Projects

1. MoneyMate – Financial Literacy Platform
2. North Star – Career Readiness Platform
3. Somaiya Unplugged – Student Engagement Event
4. BrewTile – Sustainable Flooring Innovation
5. Reformed – Waste Repurposing Concept
6. SoilBoost – Sustainable Agriculture Concept

## Technologies Used

- HTML5 – Website structure and semantic elements.
- CSS3 – Styling, layouts, animations and responsive design.
- Google Fonts – Typography.
- Flexbox and CSS Grid – Page layout and alignment.
- CSS Media Queries – Mobile and tablet responsiveness.
- CSS Transitions and Keyframes – Animations and hover effects.

## Design Highlights

- Elegant brown, cream and ivory colour palette.
- Responsive layout for desktop, tablet and mobile.
- Animated sections and interactive hover effects.
- Modern typography and structured project cards.
- Sticky navigation for easy browsing.
